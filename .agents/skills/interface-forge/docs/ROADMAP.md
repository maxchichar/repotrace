# Roadmap and release gates

## v1.0 — packaged (2026-10-18)

- Open Agent Skills metadata and modular references
- Research-first RPI-V workflow and product-aware decisions
- Source/licensing cautions, security and accessibility/performance targets
- Project memory templates, read-only inspector, validator, safe installer
- Evaluation cases and scoring specification

## v1.1 — after real evals

- Run matched control/equipped agent tasks using 3 representative repositories and all evaluation prompts.
- Collect actual screenshots (desktop/mobile), accessible interaction recordings, log evidence and review results.
- Fix any inconsistent instructions, false-positive package checks or ambiguous gates.
- Add examples from owned projects, with permissions and no secrets.

## v1.2 — optional integrations

- Adapter guidance for specific frameworks/test runners (Next/React, Vue/Nuxt, SvelteKit).
- Optional screenshot/axe Playwright example project—not injected blindly into target repos.
- Token import adapters; explicit opt-in to external services.
- Visual regression CI reference patterns and offline coverage where available.

## Release safeguards

Do not claim external design effectiveness before real blind comparison. Maintain dependency/license/source review dates. No third-party component code is bundled without separate review.
