# Art direction: distinctive, defensible, adaptable

Visual identity is a decision system, not a gallery of fashionable tricks.

## Design-read statement

Before drawing: "For [audience] performing [job] under [constraints], the interface should feel [three adjectives] through [specific typography/layout/color/content/motion strategy], while avoiding [relevant risk]."

Examples:
- "For multi-branch finance managers reconciling exceptions under time pressure: forensic, calm, precise; high-density numerals, strong state indicators, quiet neutral surfaces, one restrained action accent. Avoid novelty animations obscuring the evidence."
- "For an editorial portfolio introducing the author's worldview: deliberate, personal, architectural; high-contrast expressive title, powerful whitespace, restrained transitions, authentic photography. Avoid a generic three-card SaaS hero."

## Composition and hierarchy

- Begin with content priority. Choose a grid or layout motivated by reading order, task sequence and attention.
- Establish clear macro/micro hierarchy: page title, primary task, supporting context, controls, metadata.
- Build rhythm using an explicit spacing scale; vary pacing intentionally, not randomly.
- Use asymmetry for a purpose; never make meaningful content hard to find for aesthetics.
- Use whitespace to distinguish groups, but do not force huge gaps in frequent-use enterprise tools.
- Treat data numerals carefully: tabular figures, units, decimal alignment, source and period.

## Typography

Define body, heading, display, label, data, and code roles. Choose high-quality accessible fonts compatible with language support, licensing, load strategy, available weights, fallbacks. Set line height, max measure, letter spacing and tracking consciously. Large type is not automatically high quality; readable hierarchy matters more than fashion. Honor existing brand fonts on redesigns unless there is evidence to change them.

## Color and surfaces

Use semantic tokens: canvas, surface, elevated, text, muted, border, action, accent, positive, warning, destructive, info. Ensure state not encoded in color alone; contrast and dark-mode behavior must be reviewed. Accent colors should signal action or identity, not appear everywhere. Design for actual assets/brand, not default purple just because the AI prefers it.

## Imagery and authenticity

Prefer genuine product interfaces, authentic photography, original artwork or properly licensed assets where they make the proposition clearer. Don't invent client logos, photos, customer ratings, fake charts or project screenshots. Abstract graphics must not compete with core content.

## Animation art direction

Declare motion tone (none/subtle/expressive) and roles (orientation, feedback, storytelling). Keep visual novelty proportional to product genre and user tolerance. Follow `motion-effects.md`.

## Comparative direction exercise (Full mode)

When brief is open-ended, propose 2–3 directions with:
- Name + design-read + reason it fits audience
- Typography family/role reasoning, neutral/accent strategy, grid and density
- Hero/dashboard/flow concept
- Distinctive element grounded in product
- Risks (readability, speed, cost, brand mismatch)
- One recommended direction, with an explicit trade-off

Avoid the anti-pattern of banning all gradients, cards, sans-serif type, dark themes, or glassmorphism. These techniques are only bad when misapplied. "Not AI-ish" translates into specificity, original composition, accurate content, restrained effects and consistency—not an arbitrary prohibition list.

## Craft critique

Can a newcomer tell what the product is, who it helps, and what to do? Does the first viewport contain meaningful information rather than decoration? Does the visual system have one recognizable logic across pages and states? Does it still work without animation, large monitor or perfect assets?
