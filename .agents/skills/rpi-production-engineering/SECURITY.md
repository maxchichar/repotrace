# Security policy

This repository provides process guidance and local evidence-gate tooling. It does not guarantee secure or compliant applications.

If you find a security issue, avoid posting exploit payloads, tokens, or customer data in public issues. Contact the repository maintainer through a private GitHub security advisory after repository security reporting is enabled, or another private channel explicitly published by the maintainer. Do not assume private reporting is configured until verified.

Do not treat automatically generated evidence as an authenticated sign-off. Authorized reviews and release approvals must be verified in the system of record.
